# Competitive Analysis Skill

Kiro AI 竞品分析技能，用于对任意产品进行系统化的竞品调研分析。

## 功能说明

当你在 Kiro 中说"帮我做个竞品分析"或"分析一下市面上类似的产品"时，AI 会自动执行完整的 10 步分析流程。

## 执行流程

| 步骤 | 内容 | 输出 |
|------|------|------|
| 1 | 明确分析对象 | 产品定位、目标用户、技术栈 |
| 2 | 竞品识别与分类 | 5-8 个竞品 + 分类表 |
| 3 | 逐个竞品详细分析 | 每个竞品的详细表格 |
| 4 | UI 交互与设计风格分析 | 交互范式 + 视觉建议 |
| 5 | 功能对比矩阵 | 横向对比表（✅⚠️❌） |
| 6 | 市场热度数据 | GitHub stars / 用户量 / 融资 |
| 7 | 用户需求与痛点挖掘 | GitHub Issues + PRs 分析 |
| 8 | 视觉素材收集 | 截图/动图下载到本地 |
| 9 | 综合输出 | 完整 Markdown 报告 |
| 10 | PRD 差距分析（可选） | 功能 gap + 建议 |

## 输出结构

```markdown
# [产品名] 竞品分析报告
## 一、TL;DR（一句话结论）
## 二、竞品详细分析
## 三、UI 交互模式与设计风格分析
## 四、竞品视觉素材库
## 五、竞品功能对比矩阵
## 六、市场热度数据分析
## 七、用户需求与产品痛点挖掘
## 八、核心竞争优势
## 九、竞品的可借鉴点
## 十、市场定位图
## 十一、功能清单（☐/☑ 勾选式 backlog）
## 十二、建议优先级路线图
## 十三、数据来源
```

## 使用方式

在 Kiro 中：

1. 输入 `#competitive-analysis` 或直接说"帮我做竞品分析"
2. 回答 AI 的几个确认问题（产品定位、目标用户等）
3. AI 自动执行完整分析流程
4. 输出报告到项目根目录 `竞品分析报告.md`

## 数据来源

- GitHub REST API（stars、issues、PRs）
- Web 搜索（融资、用户量等公开数据）
- 竞品官网和 README（截图、功能描述）

## 依赖工具

- `remote_web_search` - 网络搜索
- `web_fetch` - 网页内容抓取
- `execute_bash` + curl - GitHub API 调用
- `fs_write` - 文件写入
