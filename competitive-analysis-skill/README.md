# Competitive Analysis Skill

Kiro AI 竞品分析技能，用于对任意产品（软件/硬件/SaaS）进行系统化的竞品调研分析。

## 功能说明

当你在 Kiro 中说"帮我做个竞品分析"或"深度调研某产品"时，AI 会自动执行完整的分析流程，输出结构化的 Markdown 报告。

## 支持的分析类型

| 类型 | 适用场景 | 模板 |
|------|----------|------|
| **软件/开源项目** | GitHub 项目、SaaS 产品、App | `competitive-analysis.skill.md` |
| **硬件产品** | 可穿戴设备、IoT、消费电子 | `hardware-analysis.skill.md` |

## 执行流程

### 通用流程（10步）

| 步骤 | 内容 | 输出 |
|------|------|------|
| 1 | 明确分析对象 | 产品定位、目标用户、技术栈 |
| 2 | 竞品识别与分类 | 5-8 个竞品 + 分类表 |
| 3 | 逐个竞品详细分析 | 每个竞品的详细表格 |
| 4 | UI/UX 交互分析 | 交互范式 + 视觉建议 |
| 5 | 功能对比矩阵 | 横向对比表 |
| 6 | 市场热度数据 | GitHub stars / 用户量 / 融资 |
| 7 | 用户需求与痛点挖掘 | Issues + 评论分析 |
| 8 | 视觉素材收集 | 截图/图表下载到本地 |
| 9 | 综合输出 | 完整 Markdown 报告 |
| 10 | 差距分析（可选） | 功能 gap + 建议 |

### 硬件产品额外步骤

| 步骤 | 内容 | 输出 |
|------|------|------|
| H1 | 硬件规格对比 | 传感器/芯片/BOM 对比表 |
| H2 | 商业模式分析 | 定价/订阅/渠道/TCO 计算 |
| H3 | 供应链与制造 | 代工/认证/成本结构 |
| H4 | SWOT 分析 | 优劣势/机会/威胁 |

## 格式规范

### ASCII 图表规则（重要）

代码块内的图表必须遵循以下规则，避免在 Obsidian/Markdown 中显示错位：

1. **禁止在 `|` 边框行内使用中文字符** — 中文占2字符宽度会导致右侧边框错位
2. 代码块内标签使用英文，中文说明放在代码块外面
3. 使用纯 ASCII 字符: `+ - | = * o ~ < >`
4. **禁止** Unicode box-drawing 字符: `┌┐└┘├┤│─╭╰█░━◄►←→┼┬●`
5. 如需中文标注，使用无边框格式（去掉外框）
6. 小框内容保持纯英文，确保每行等宽对齐

### 图片处理规则

1. 优先下载到本地 `Attachments/` 文件夹
2. 下载后验证：`file` 命令检查类型 + 大小 > 10KB
3. **禁止**使用 Unsplash 等通用素材图替代产品图
4. 无法获取时，使用 ASCII 图表 + 外部链接引用
5. Obsidian 图片引用格式: `![[filename.ext]]`

### 数据来源规范

- 每个关键数据点标注来源和日期
- 价格数据区分：官方价 / 促销价 / 渠道价
- 用户数据标注统计口径（MAU / 注册 / 付费）
- 融资数据交叉验证（至少2个来源）

## 使用方式

在 Kiro 中：

1. 输入 `#competitive-analysis` 或说"帮我做竞品分析"/"深度调研XX产品"
2. 回答 AI 的确认问题（产品定位、目标用户等）
3. AI 自动执行完整分析流程
4. 输出报告到指定目录
