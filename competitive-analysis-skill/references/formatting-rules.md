# Formatting Rules

竞品分析报告的格式规范，确保在 Obsidian 和其他 Markdown 渲染器中正确显示。

## ASCII 图表规则

### 核心原则

中文字符在等宽字体中占 **2个英文字符宽度**。当中文出现在 `|` 边框行内时，右侧边框会错位。

### 规则清单

| # | 规则 | 原因 |
|---|------|------|
| 1 | 代码块内 `\|` 边框行禁止中文 | 中文占2宽度导致错位 |
| 2 | 标签/标题用英文 | 确保等宽对齐 |
| 3 | 中文说明放代码块外 | 正文不受等宽限制 |
| 4 | 只用纯 ASCII 字符 | 跨平台兼容 |
| 5 | 禁止 Unicode box-drawing | 部分字体渲染宽度不一致 |
| 6 | 无边框格式优先 | 避免对齐问题 |

### 允许的字符

```
边框: + - | 
填充: = * o ~ # @
箭头: < > v ^
分隔: --- ===
```

### 禁止的字符

```
Box-drawing: ┌ ┐ └ ┘ ├ ┤ │ ─ ╭ ╰ ╮ ╯ ┼ ┬
Block:       █ ░ ▓ ▒
Arrow:       ← → ↑ ↓ ◄ ► ▼ ▲
Special:     ● ○ ◉ ━ ≋
```

### 正确示例

```
Product Line Comparison

+-----------+    +-----------+    +-----------+
| Watch Pro |    | Band Lite |    | Ring      |
| $399      |    | $99       |    | $299      |
| AMOLED    |    | Screenless|    | No screen |
+-----------+    +-----------+    +-----------+
```

> 上方为产品线对比：Watch Pro（高端智能手表）、Band Lite（入门追踪器）、Ring（指环形态）

### 错误示例

```
| 智能手表   |    | 追踪器    |    <-- 右侧 | 会错位！
```

## Markdown 表格规范

- 表头使用 `**粗体**` 标注重要维度
- 对齐方式：左对齐（默认）或居中 `:---:`
- 单元格内避免超长文本，超过30字换行或缩写

## 标题层级

```
# 一级：报告标题
## 二级：大章节（一、二、三...）
### 三级：子章节（3.1、3.2...）
#### 四级：细分内容（极少使用）
```

## 引用与来源

- 外部链接格式：`[显示文本](URL)`
- 数据来源标注：在数据后括号内注明 `（来源: XX, 2026.5）`
- 报告末尾统一列出所有参考来源
