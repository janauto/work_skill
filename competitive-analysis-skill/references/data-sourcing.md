# Data Sourcing Rules

调研数据的获取、验证和标注规范。

## 数据可信度分级

| 等级 | 来源类型 | 示例 |
|------|----------|------|
| A | 官方发布 | 公司官网 spec 页、SEC 文件、官方博客 |
| B | 权威媒体 | CNBC、Bloomberg、TechCrunch、The Verge |
| C | 行业分析 | Counterpoint、IDC、Gartner |
| D | 评测/社区 | Reddit、YouTube 评测、个人博客 |
| E | 估算/推测 | 基于公开数据的推算 |

## 各类数据的获取规范

### 产品规格

| 数据 | 首选来源 | 备选来源 |
|------|----------|----------|
| 尺寸/重量 | 官网 spec 页 | gadgetsandwearables.com |
| 传感器 | 官网 spec 页 | 拆解报告 (iFixit, TechInsights) |
| 电池续航 | 官网声明 | 评测实测数据 |
| 防水等级 | 官网 spec 页 | 认证文件 |

### 价格信息

| 数据 | 标注方式 |
|------|----------|
| 官方定价 | `$99.99 (官方价, 2026.5)` |
| 促销价 | `$79.99 (促销价, 限时)` |
| 订阅价 | `$199/年 (年付) / $24/月 (月付)` |
| 历史价 | `$699 → $499 (降价后)` |

### 用户/市场数据

| 数据 | 标注方式 |
|------|----------|
| 用户数 | `250万+ (2026.3, 来源: CNBC)` |
| 收入 | `$11亿年化 (2025年底, 来源: TechCrunch)` |
| 估值 | `$101亿 (G轮, 2026.3, 来源: Mubadala官方)` |
| 市场份额 | `约15% (估算, 基于XX数据)` |

### 融资数据

**必须交叉验证（至少2个来源）：**
- 来源1: 公司官方新闻稿 / 投资方公告
- 来源2: TechCrunch / Bloomberg / Crunchbase

## 网络搜索策略

### 第一轮：基础信息

```
搜索词: "[产品名] specs dimensions weight battery"
搜索词: "[产品名] price subscription cost"
搜索词: "[公司名] founded history funding"
```

### 第二轮：深度信息

```
搜索词: "[产品名] teardown sensor PCB"
搜索词: "[产品名] vs [竞品名] comparison 2026"
搜索词: "[公司名] revenue users valuation 2026"
```

### 第三轮：用户反馈

```
搜索词: "[产品名] review pros cons"
搜索词: "[产品名] reddit user experience"
搜索词: "[产品名] problems issues complaints"
```

## 网络爬取容错

| 情况 | 处理 |
|------|------|
| 普通 fetch 失败 | 尝试 rendered 模式 |
| rendered 超时 (30s) | 放弃该来源，换备用 |
| 403 Forbidden | CDN 防盗链，换来源 |
| 搜索 snippet 已有足够信息 | 不必强制 fetch 全文 |
| 单个 URL 失败 2 次 | 标记为不可用，换来源 |

## 数据标注格式

### 在正文中标注

```markdown
Whoop 全球用户突破 250万（来源: [CNBC Disruptor 50](URL), 2026.5）
```

### 在表格中标注

```markdown
| **全球用户** | 250万+ (2026.3) |
```

### 在报告末尾汇总

```markdown
## 参考来源

- [Whoop官网](https://www.whoop.com) - 产品规格
- [CNBC Disruptor 50 2026](URL) - 用户数、收入数据
- [Mubadala官方公告](URL) - G轮融资数据
- [Gadgets & Wearables](URL) - 技术规格对比
```

## 数据时效性

| 数据类型 | 有效期 | 过期处理 |
|----------|--------|----------|
| 产品规格 | 产品生命周期内 | 标注版本号 |
| 价格 | 3个月 | 标注查询日期 |
| 用户数 | 6个月 | 标注数据日期 |
| 融资 | 永久有效 | 标注轮次和日期 |
| 市场份额 | 1年 | 标注报告来源和年份 |

## 注意事项

- 不要把"估算"当"事实"呈现
- 竞品的自我宣传数据需标注"官方声称"
- 第三方评测数据可能有偏差，标注来源
- 中国市场数据和海外市场数据分开标注
- 汇率换算标注使用的汇率和日期
